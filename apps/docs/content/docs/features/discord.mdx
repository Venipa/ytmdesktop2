Discord Rich Presence displays the current track title and artist in your Discord status while YTMDesktop2 is playing.

![Discord Rich Presence](/images/features-rpc2.png)

## Setup

1. Open **Settings → Discord**.
2. Enable Rich Presence.
3. Start playback — Discord should show the track after a short settle.

## Notes

- Presence follows play/pause and track changes from the embedded YouTube Music player.
- Disable Discord from settings when you want a private session.
