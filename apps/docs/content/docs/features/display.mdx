---
title: Display
description: Scale the YouTube Music view with zoom
---

Adjust how large YouTube Music renders inside the app without changing toolbar, settings, or tray view chrome.

## Setup

1. Open **Settings → Appearance → Display**.
2. Drag **YouTube zoom** between **80%** and **150%** (5% steps).
3. Changes apply live to the YouTube Music view only.

Use **Reset to 100%** to restore the default scale. OS display scaling still applies on top — see [DPI & scaling](/docs/features/dpi).
