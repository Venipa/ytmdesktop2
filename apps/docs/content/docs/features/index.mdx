YTMDesktop2 extends YouTube Music with desktop-focused tools — scrobbling, Discord presence, tray view, synced lyrics, `ytmd://` shared links, UI enhancement plugins, themes, DPI-aware scaling, and OBS overlays.

![Full player](/images/player-full.png)
