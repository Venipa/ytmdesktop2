## Downloads

Grab the latest build from the [landing page](/) (OS is auto-detected) or from GitHub Releases on the repository.

| Platform | Artifact | Notes |
| --- | --- | --- |
| Windows | `*-setup.exe` (NSIS) | Current releases |
| macOS Apple Silicon | `.dmg` / `.zip` (arm64) | Shown on the landing page when published |
| macOS Intel | `.dmg` / `.zip` (x64) | Shown on the landing page when published |
| Linux | `.AppImage` / `.deb` | Current releases |
| Linux Flatpak | `YouTube-Music-for-Desktop-*-x86_64.flatpak` | Sideload: `flatpak install ./….flatpak` |
| Linux Snap | `YouTube-Music-for-Desktop_*_amd64.snap` | Sideload: `sudo snap install --dangerous ./….snap` |
| Linux Pacman | `ytmdesktop2-*-x86_64.pacman` | Sideload: `sudo pacman -U ./….pacman` |

macOS tabs stay visible even before assets ship — once Apple Silicon and Intel `.dmg` / `.zip` builds are attached to a release, both show in the listing (Apple Silicon preferred when detected).

## First launch

1. Install or unpack the build for your OS.
2. Sign in to YouTube Music in the embedded browser.
3. Open **Settings** to enable integrations (API, Last.fm, Discord, Stream Deck).

## Updates

Official builds use electron-updater against GitHub Releases. Keep the app updated for security and feature fixes.
