**YTMDesktop2** is an Electron desktop client for YouTube Music with Last.fm scrobbling, Discord Rich Presence, custom CSS, mini player, OBS overlays, local API, and Stream Deck support.

## Stack

- Electron + React (renderer)
- tRPC for main ↔ renderer IPC
- Local HTTP API for integrations
- Stream Deck plugin in `packages/streamdeck`
