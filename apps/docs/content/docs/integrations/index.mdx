Integrations use the [local API](/docs/api) and optional [Authentication](/docs/api/authentication).

In the app: Settings → **API & Integrations**.

| Integration | Status |
| --- | --- |
| [Remote](/docs/integrations/remote) | Coming soon |
| [Stream Deck](/docs/integrations/streamdeck) | Available |

## Prerequisites

1. Enable the [Local API](/docs/api).
2. Turn on [Authentication](/docs/api/authentication) when the client must pair.
3. See [API routes](/docs/api/routes) for HTTP/WS endpoints clients call.
