Authorize a mobile companion by scanning a QR code.

<Callout type="warn" title="Coming soon">
  Remote pairing is not available yet. It will use the same global authentication unit as Stream Deck and the local API.
</Callout>

## Planned flow

1. Enable [Local API](/docs/api) and [Authentication](/docs/api/authentication).
2. Open Settings → **API & Integrations** → **Remote**.
3. Scan the QR code from the companion app.
4. Approve the pending request under Authentication.
